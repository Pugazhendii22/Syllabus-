# Ammu’s teaching studio

A mobile-oriented study space for the Pondicherry University B.A. (Honours) English syllabus (2023–24 onward). Run with Python 3; the app itself requires no third-party packages:

```sh
cd teaching-studio
python server.py
```

Open http://localhost:8000 on the same machine. Choose a semester, subject and unit, then tap one of the visible buttons under **Choose notes to read**. Tap outside a subject, unit or class-length picker to close it without changing your selection. Reading size, saved notes and bookmarks are stored in the current browser on that device; they do not sync.

## Install on a phone

On iPhone or iPad, open the deployed HTTPS site in Safari, tap **Share → Add to Home Screen → Add** (leave “Open as Web App” on if shown). On Android, use the app’s Add to home screen button or the browser menu. If an older shortcut shows the wrong icon, remove that shortcut and add it again after the updated site is deployed. Removing a shortcut can remove its separate browser storage: keep a copy of saved material first. Different browser and installed-app storage may not sync.

To refresh, go to the top of the page and pull down until the circular arrow turns upward, then let go. A spinner shows while the app reloads. You can also tap the refresh icon in the top bar. When a newly installed update is ready, a notice offers Reload now or Later. Unsent text is not saved on reload; the app asks before clearing typed text. If offline, refreshing can only show cached content. Update notifications depend on service-worker support and a successful online update check.

After a successful online visit and service-worker installation, the app shell and currently prepared notes can be used offline on supported browsers. External references and optional AI need the internet; browser storage may be cleared or evicted. Updates download when online and can require closing and reopening the app. Real iOS/Android install and offline behaviour has not been independently tested.

**Vercel:** `server.py` is not run on Vercel. Instead, the serverless functions `api/status.js` and `api/chat.js` provide `/api/status` and `/api/chat` with the same behaviour. In the Vercel project go to Settings, Environment Variables, add `AI_API_KEY`, `AI_MODEL` and `AI_BASE_URL` (an OpenAI-compatible HTTPS base such as `https://api.openai.com/v1`), then redeploy. Keys stay on the server. The functions accept same-origin requests only and apply a small best-effort rate limit; set a spending cap with your AI provider as well, because the site is public. Prepared notes do not need an API.

## Optional AI

The authored notes work without AI or a key. The optional AI tools require a real OpenAI-compatible provider and server-side configuration:

```sh
AI_API_KEY='your-key' AI_MODEL='your-model' AI_BASE_URL='https://your-provider.example/v1' python server.py
```

The server appends `/chat/completions` to the HTTPS base URL. Provider availability, free quotas and prices vary. Restart after changing configuration; do not share or commit keys. The simple server is for trusted local/private use, not public deployment without authentication, rate limiting and further security. AI output must be checked.

## Developer notes

The existing `prepared-notes.json` is the canonical accumulated dataset. **Do not run `create_notes.py` by itself:** it overwrites the file and erases later additions. Subsequent `add_*.py` and `expand_visual_media.py` scripts add or replace specific unit entries; rerunning them can overwrite manual changes to those units. The targeted `fix_sem3_notes.py` applies this audit and is safe to rerun; do not rerun older scripts over its edits. Earlier additions include `add_functional_ii.py`, `add_functional_writing.py` `add_language_studies.py`, `add_american_literature.py`, `add_american_fiction.py`, `add_indian_poetry_start.py`, `add_indian_unit1.py` `add_indian_novels.py`, `add_indian_remaining.py`, `add_environment.py`, `add_criticism_i.py`, `add_shakespeare.py`, `add_indian_ii.py`, `add_internship.py` `add_new_literatures.py` `add_linguistics.py` `add_modern_poetry.py` `add_modern_drama.py` `add_modern_fiction.py` `add_subaltern_literature.py` and `add_indian_aesthetics.py`.

Automated checks have included JavaScript syntax, JSON parsing, fake-DOM interaction tests, simulated PWA/service-worker tests and HTTP responses. Testing in a real mobile browser and assistive-technology accessibility testing have not yet been performed.
