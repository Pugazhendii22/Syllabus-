GETTING STARTED

Connect your AI

Connect any provider with an OpenAI-compatible chat completions API. Your key stays on the server, not in the browser.

AI_API_KEY="your-key" \
AI_MODEL="your-model" \
AI_BASE_URL="https://provider.example/v1" \
python server.py

This command runs the local Python server. On Vercel, the included /api functions do the same job: add AI_API_KEY, AI_MODEL and AI_BASE_URL under Project Settings, Environment Variables, then redeploy. Prepared notes work without AI. Never put a secret key in browser code. Free tiers may have limits or change; AI output needs review.
